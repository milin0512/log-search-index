ログ検索インデックス 取扱説明書

最終更新: 2026-10-18

  • 過去のTRPGセッションのログ(ココフォリアの書き出しHTML、CClogのプレビュー用HTML)をまとめて取り込み、セッションをまたいでキーワード検索・キャラクターでの絞り込み・閲覧ができる
  • ログの保管庫ではなく、NotionやGoogleドライブに置いてあるログを横断検索するための「索引(インデックス)」という位置づけ。元のログファイルは書き換えない
  • 読み込んだログの内容はすべて端末内で処理される。どこかのサーバーに送信されることはない

基本の流れ

  • ①ココフォリアの書き出しHTML、またはCClogのプレビュー用HTMLを用意する
  • ②サイドメニューの「ファイルを選ぶ(複数可)」(PCなら「フォルダを選ぶ」も可)でログを読み込む
  • ③セッション一覧から読みたいセッションを開く。「前へ」「次へ」で隣のセッションへ移動できる
  • ④サイドメニューの「検索・絞り込み」で、キーワードやキャラクターから目的の場面を探す
  • ⑤取り込みが終わったら、案内に従ってバックアップを書き出しておく(下記＜バックアップ＞参照)

サイドメニュー

  • 画面右上の「☰」を押すと開く。画面幅900px以上(PCやiPadの横向きなど)では左側に常に表示される
  • 上から順に「セッション一覧に戻る」(個別セッションを閲覧しているときだけ表示)、「セクション」、「ログの読み込み」、「並べ替え」、「検索・絞り込み」、「バックアップ」、「取扱説明書を開く」が並ぶ
  • 絞り込み中は「☰」に印が付く
↑ 目次へ

ログを読み込む

  • 読み込めるのは次の3種類。どれかを選ぶ操作は不要で、自動で判別する
    • ココフォリアの書き出しHTML(新しい形式)
    • ココフォリアの書き出しHTML(以前の形式)
    • CClogが書き出したプレビュー用HTML
  • 「ファイルを選ぶ(複数可)」: ログのHTMLを1つ以上選んで読み込む
  • 「フォルダを選ぶ」(PCのみ): Googleドライブ for デスクトップで同期しているログフォルダなどを、丸ごと読み込める。iPhone・iPadでは使えないためボタンは表示されない
  • すでに取り込んであるログと同じファイル名のものは、内容が変わっていれば自動で最新版に差し替え、変わっていなければ何もしない。差し替えても一覧の並び順は変わらない
  • 同じファイル名のものがない新しいログの扱い
    • フォルダから読み込んだ場合: 新規として自動で追加される
    • ファイルを選んで読み込んだ場合: 「読み込んだログの扱いを選ぶ」画面が出る。新しいログなら「新規として追加」、ファイル名を変えて保存し直した更新版なら、置き換えたい既存のセッションを選ぶ
  • 読み込み結果(新規追加・差し替え・変更なしの件数、読み取れなかったファイル)は、ボタンの下に表示される
  • ファイル名から、シナリオ名と日付を自動で拾う。日付がファイル名にないココフォリアの新しい形式のログは、ログの最初の発言の日時をセッション日付にする
  • 取り込みは、表示中のセクションに対して行われる(下記＜セクション＞参照)
↑ 目次へ

セクション

  • セクションは、セッション一覧を丸ごと分ける「別々の本棚」。たとえば「キャンペーンA」と「単発シナリオ」のように分けておける
  • 一覧・検索・絞り込み・前へ/次への移動は、表示中のセクションの中だけで行われる。同じファイル名の自動差し替えも、表示中のセクションの中だけで判定される
  • 「新しいセクションを作る」: 名前を入力して新しいセクションを作り、そのセクションに切り替わる(名前を空欄にすると「セクション2」のような名前になる)
  • 「セクション履歴(編集が新しい順)」: すべてのセクションが、最後に編集した順に並ぶ。行を押すと、そのセクションに切り替わる。表示中のセクションには「(表示中)」が付き、ピンクの枠で囲まれる
    • ここでいう「編集」は、ログの追加・差し替え・削除・並べ替えのこと。セクションを切り替えたり、ログを読んだりしただけでは並び順は変わらない
    • 各行に、セッションの件数と最終編集日時が表示される
  • 別のセクションへ移るとき、個別セッションを読んでいた場合はその場所を覚えておき、戻ってきたときに同じセッションの同じ位置から再開する。一覧画面にいた場合は一覧に戻る
  • セクションを切り替えると、検索・絞り込みと並び替えモードは解除される
  • 「名前を変更」: そのセクションの名前を変える
  • 「削除」: そのセクションを、中のセッションごとインデックスから削除する(確認ダイアログあり、元に戻せない)。セクションが1つしかないときは削除できない
  • キャラクターの統合・KP/PLの設定は、すべてのセクションで共通
  • セクション機能ができる前に取り込んでいたログは、すべて「セクション1」に入っている
↑ 目次へ

セッション一覧

  • 表示中のセクションのセッションが、上から順に並ぶ。各行にシナリオ名・日付(拾えなかった場合は「日付不明」)・発言件数が表示される
  • 一覧の上に、表示中のセクション名が表示される
  • 行を押すと、そのセッションの個別閲覧画面に移る
  • 「削除」で、そのセッションをインデックスから削除できる(確認ダイアログあり)。元のログファイルは消えない
  • 並び順の初期配置: 日付が拾えたログは日付順に、拾えなかったログは取り込んだ順に末尾へ並ぶ。並び順は手動で変えられる(下記＜並べ替え＞参照)
↑ 目次へ

並べ替え

  • サイドメニューの「並び替えモードに切り替える」を押すと、並び替えモードになる。誤タップを防ぐため、このモードのときだけ並べ替えができる
  • 各行の左に出るハンドル(≡)をつかんで上下にドラッグすると、順番を変えられる。指を離したときの並びが保存される
  • ハンドルをつかんだまま画面の上端・下端の近くまで持っていくと、つかんだまま画面がスクロールする。端に近いほど速くスクロールする。画面に収まらない離れた位置へも、そのまま運べる
  • 並び替えモードを終えるときは、画面最下部の「並び替えモードを終了する」を押す。並び替えモード中は、サイドメニューの「並べ替え」欄は表示されない
  • 並び替えモードに切り替えると、検索・絞り込みは解除される
↑ 目次へ

個別セッションの閲覧

  • 画面の上部と最下部に「前へ」「次へ」ボタンがあり、一覧に戻らずに隣のセッションへ移動できる(長いログを読み終えたとき、先頭へ戻らずに次へ進める)
  • タイトルの下に、日付と「何番目/全何件」が表示される
  • セッションごとに読んでいた位置を覚えていて、別のセッションへ移ってから戻ってきても、同じ位置から再開できる
  • 一覧に戻るときは、サイドメニューの「セッション一覧に戻る」を押す

発言の表示のされ方

  • KP・PLの発言: 地の文として「名前：本文」の1行で表示し、左に色の帯が付く(KPは青、PLは茶色)
  • ダイスロールの発言: 発言者にかかわらず、地の文の見た目で表示する(本文に「1D100」のような「数字D数字」と「＞」が含まれるものをダイスロールとみなす)
  • キャラクターの発言: 色付きの名前の下に、吹き出しで本文を表示する
  • システムメッセージ(SAN値やHPの変化の通知など、発言者のいないもの): 枠で囲んだ、灰色の小さめの文字で表示する。発言者名は出さない
  • infoタブの発言は、少し字下げした枠で表示する。otherタブの発言は、全体を灰色で表示する

KP・PL(地の文)の設定

  • 名前が「KP」「PL」の発言者(全角・半角、大文字・小文字の違いは無視)は、最初からKP・PLとして地の文で表示される
  • それ以外の発言者をKP・PLとして扱いたいときは、サイドメニューの「KP・PL(地の文)を設定する」を押し、発言者ごとに「KP(地の文)」「PL(地の文)」「キャラクター」を選ぶ。選ぶとすぐ表示に反映される

キャラクターの統合

  • 同じ名前で、色なしと色ありの発言が混ざっている発言者は、自動で色ありの方にそろえて1人として扱う
  • サイドメニューの「キャラクターを統合・解除する」から、選んだ2人以上の発言者を1人のキャラクターにまとめられる(例: 「立花 果凛」と「立花　果凛」)
    • 「代表の名前」で、まとめたあとに使う名前を選ぶ(最初は発言数が一番多い名前)
    • まとめたキャラクターは、絞り込みでは1人として扱われ、ログの表示も代表の名前と色になる。元のログファイルは書き換えない
    • 「統合済み」の一覧から、まとめたものを解除できる
  • 「統合候補(表記ゆれ)」: スペースの有無・全角半角・末尾の読み仮名(「立花 果凛（たちばな かりん）」のような括弧書き)だけが違う名前が提案される。自動ではまとめないので、「選ぶ」を押してから「統合する」を押す

検索・絞り込み

  • 「キーワード検索」に言葉を入れる、または「キャラクターで絞り込む」で発言者にチェックを入れてから、「検索・絞り込みを実行」を押す
    • キャラクターは複数選べる。複数選んだときは、選んだうちの誰かの発言が対象になる(OR)
    • キーワードとキャラクターを両方指定すると、「選んだキャラクターの発言のうち、キーワードを含むもの」が対象になる
    • キーワードは英字の大文字・小文字を区別しない
    • キャラクターの一覧は、表示中のセクションの中で発言数が多い順に並ぶ
  • 実行すると「検索結果」の画面になり、一致した発言がセッションごとに一覧で表示される
    • セッションごとに見出し(タイトル・日付・そのセッションの一致件数)が付く
    • 各行には発言者と本文の抜粋(キーワードの少し前から、最大3行)が出て、キーワードは濃い黄色で強調される
    • 一致が100件を超えるときは最初の100件だけが表示され、一番下の「さらに表示(残り○件)」で100件ずつ追加できる
  • 一覧の行を押すと、そのセッションの該当する発言の場所へ移動する。一致した発言は黄色の背景、キーワードは濃い黄色で強調される
  • セッションのタイトルの下に出る「○ / ○ 件」のバーの「◀」「▶」で、前後の一致箇所へ移動できる(別のセッションの一致箇所へもそのまま移る)。「一覧」で検索結果の一覧に戻る(前に見ていた位置から再開する)。「×」で絞り込みを閉じる
    • 「◀」「▶」を続けて押している間は件数の表示だけが進み、押すのを止めると(約0.3秒後)その一致箇所へ移動する。iPhoneなどで連打してもページが落ちにくくするため
  • 絞り込み中にサイドメニューの「セッション一覧に戻る」を押すと、一致した発言のあるセッションだけが表示され、各行に一致件数が出る
  • 「絞り込みを解除」で元に戻る(検索結果の画面にいたときはセッション一覧に戻る)。サイドメニューに今の絞り込み条件とヒット件数が表示される
  • 検索の対象は、表示中のセクションのセッションだけ

バックアップ

  • このツールのデータは、ブラウザの中に保存されている。ブラウザのデータを消したときや、iPhone・iPadのSafariで長いあいだ開かなかったときなどに消えることがあるので、バックアップを書き出しておく
  • ログを取り込んだり差し替えたりすると、「バックアップを書き出しますか?」という案内が出る。「書き出す」でバックアップファイル(.json)が保存される
  • サイドメニューの「インデックス全体を書き出す」でも、いつでも書き出せる。書き出しは、すべてのセクションをまとめて1つのファイルに保存する(キャラクターの統合・KP/PLの設定も含む)
  • 「バックアップファイルを読み込む」で読み込むと、読み込み方法を選ぶ画面が出る
    • 復元(全置換): 今のインデックスをすべて、バックアップの内容に置き換える。セクションの構成も元に戻る(確認ダイアログあり、元に戻せない)。セクション機能ができる前のバックアップは、1つのセクションにまとめて復元される
    • 統合(マージ): バックアップの中のセッションを、表示中のセクションに1件ずつ追加・差し替えする。「新規として追加」か、置き換えたい既存のセッションを選ぶ。複数のバックアップを1つにまとめたいときに使う

対応環境・注意点

  • 対応ブラウザ: iPhone・iPadのSafari、およびPCの一般的なブラウザ(Chrome・Edgeなど)
  • 画面幅900px以上ではサイドメニューが常に表示される2カラムの画面になる。それ未満は右上の「☰」からサイドメニューを開く
  • 通信は発生しない: 読み込んだログの内容は端末内でのみ処理され、外部のサーバーに送信されることはない
  • ダークモード: 端末の設定がダークモードの場合、自動で配色が切り替わる
  • ホーム画面に追加したアイコンについて: iPhone・iPadでホーム画面に追加している場合、ツールのアイコン画像を更新しても、すでに追加済みのショートカットには反映されない(iOSは追加した時点の画像を保存する仕様のため)。新しいアイコンにしたい場合は一度ホーム画面から削除し、追加し直す
  • データは端末(ブラウザ)ごとに別々に保存される。PCで取り込んだログをiPhoneでも見たいときは、PCで書き出したバックアップをiPhoneで読み込む

うまくいかないときは

  • ファイルを選んでもセッションが増えない → 読み込み結果の表示を確認する。「ログとして認識できませんでした」と出たファイルは、対応している3種類のログ以外のHTML
  • 「変更なし」と表示されて差し替わらない → 同じファイル名で内容も同じ。内容が変わっていれば自動で差し替わる
  • 別のセクションに取り込んだはずのログが見当たらない → サイドメニューの「セクション履歴」で、取り込んだセクションに切り替える
  • 検索しても見つからない → 検索の対象は表示中のセクションだけ。別のセクションに切り替えてから検索する
  • 並べ替えのハンドル(≡)が出ない → 並び替えモードになっていない。サイドメニューの「並び替えモードに切り替える」を押す
  • サイドメニューに「並べ替え」欄がない → 並び替えモード中は表示されない。画面最下部の「並び替えモードを終了する」を押す
  • iPhone・iPadに「フォルダを選ぶ」がない → iPhone・iPadのSafariではフォルダ選択が使えないため、表示していない。「ファイルを選ぶ(複数可)」で複数のファイルをまとめて選ぶ
  • 取り込んだログが消えた → ブラウザのデータが消えた可能性がある。書き出しておいたバックアップを「復元(全置換)」で読み込む
  • ツールを更新したはずなのに古い画面のまま → ブラウザが古いファイルを覚えている可能性がある。ページを再読み込みする(iPhone・iPadのSafariでは、一度タブを閉じて開き直す)
